# CareerVault

CareerVault is a full-stack job application tracker designed to help users organize and manage their job applications.

## Planned Features

- Add, view, edit, and delete job applications.
- Track application statuses.
- Store company details, job titles, locations, job URLs, application dates, and notes.
- Persist application data in a PostgreSQL database.
- Add authentication and automated job importing in future versions.
- Eventually introduce AI-powered skill extraction and hiring trend analysis.

## Technology Stack

- **Frontend:** React + TypeScript
- **Backend:** C# + ASP.NET Core Web API
- **Database:** PostgreSQL
- **Testing:** Automated frontend and backend tests
- **Deployment:** Azure
- **Version Control:** Git + GitHub

## Development Approach

CareerVault will be built incrementally, starting with a basic job tracker and adding features one at a time. The initial focus is on core functionality, understandable architecture, and reliable data storage.

Advanced features such as automated job importing, historical job archives, and AI analytics will be introduced in later stages.
